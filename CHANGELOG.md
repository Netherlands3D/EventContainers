# Changelog

All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2025-09-29

### Added

- Event Invokers, it is now possible to trigger events with a specific value. Sometimes you do not want the code to
  dictate the value of an event, but have it available as a preconfigured invocation during design time.
